# 跨电脑安装

1. 解压 `wechat-digital-article-skill.zip`。
2. 将解压得到的整个 `wechat-digital-article` 文件夹放入用户级 Skill 目录：
   - 当前 Codex 文档推荐：`$HOME/.agents/skills/`
   - 若目标电脑使用旧版 Codex 桌面目录：`$HOME/.codex/skills/`
3. 新建一个对话，输入 `$wechat-digital-article` 调用；如果技能列表暂未出现，重启 Codex。

也可以不显式点名：直接说“用数字媒体版排版这篇微信公众号文章”，Codex 会根据技能描述自动选择它。

官方说明：[Build skills](https://developers.openai.com/codex/skills)
